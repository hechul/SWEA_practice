# 🚀 Algorithm Problem Solving

SSAFY 코딩테스트 대비 및 알고리즘 역량 강화를 위한 문제 풀이 저장소입니다. 
주로 **Java**를 활용하며, 시뮬레이션과 완전탐색(DFS/BFS/백트래킹) 역량 향상에 집중합니다.

## 🎯 학습 목표
* **SSAFY A형(D4 수준) 완벽 대비**
* 2차원 배열 기반의 복잡한 시뮬레이션 및 방향 제어 로직 마스터
* 재귀를 활용한 상태 관리(조합, 부분집합)와 효율적인 백트래킹(상태 복구) 구현
* 단순 풀이를 넘어 가독성 좋고 유지보수하기 쉬운 클린 코드 작성

## 🛠 Tech Stack
* **Language:** Java (JDK 11+)
* **Platform:** SWEA, Baekjoon 등
