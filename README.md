## 💻 풀이 실행하기

각 Java 파일은 독립적인 문제 풀이입니다. SWEA 제출용 코드의 클래스 이름이 `Solution`인 경우, 코드를 `Solution.java`에 복사해 실행하세요.

```bash
javac Solution.java
java Solution
```

실행한 뒤 해당 문제의 입력을 입력하면 결과를 확인할 수 있습니다.
